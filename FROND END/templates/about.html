    • Microvision : Automated Cell Identification

    This project proposes an intelligent web-based system for Microorganism Classification and Identification, leveraging a hybrid deep learning and machine learning architecture. Users upload microscopic images of microorganisms, which are first processed through a ResNet18 model to extract high-level features. These features are then classified using a Random Forest model trained on a diverse image dataset. During the training phase, various models including CNN, DenseNet, MobileNet, and ResNet-based combinations were evaluated to ensure optimal accuracy and robustness. The classification system effectively distinguishes between multiple microorganism types such as Hydra, a freshwater organism with tentacles, and Paramecium, a ciliated protozoan. The application, developed using Flask, includes secure user registration and login functionalities, with data stored in a MySQL database. This tool supports researchers, students, and healthcare professionals by automating microorganism identification through image analysis.
